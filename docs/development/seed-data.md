# Dev seed data

Dev seed data активируется только при Spring profile `dev` и управляется переменной:

```env
PODCAST_DEV_SEED_ENABLED=true
```

## Состав данных

| Сущность | Плановый объём |
|---|---:|
| Пользователи | 36 |
| Авторы | 14 |
| Категории | 12 |
| Подкасты | 126 |
| Плейлисты | 72 |
| Элементы плейлистов | около 576 |
| Подписки | около 175 |
| Голоса | больше 1000 суммарно |
| История прослушивания | около 864 |
| Транскрипты и summaries | больше 200 |

Seed-подкасты содержат значения `num_speakers` от `1` до `5`. Для опубликованных и архивных выпусков заполняются `audio_url_file` и `audio_size_file`, что позволяет frontend-команде проверять отображение файловых метаданных без ручной подготовки данных.

## Основной dev-пользователь

```json
{
  "id": "00000000-0000-0000-0000-000000000001",
  "email": "dev.user@example.local",
  "username": "dev-user"
}
```

## Свойства seed

| Свойство | Поведение |
|---|---|
| Изоляция | работает только в profile `dev` |
| Идемпотентность | stable UUID и upsert |
| Реалистичность | разные статусы, даты, тексты, public/private playlists |
| Совместимость | не изменяет production profile |

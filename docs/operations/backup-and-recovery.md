# Резервное копирование и восстановление

## PostgreSQL

Основной источник состояния сервиса — PostgreSQL. Резервное копирование выполняется средствами инфраструктуры БД.

Критичные таблицы:

| Таблица | Значение |
|---|---|
| `user_profiles` | связь с пользователями auth-service |
| `author_profiles` | авторские данные |
| `podcasts` | каталог выпусков |
| `playlists`, `playlist_podcasts` | пользовательские коллекции |
| `subscriptions`, `*_votes`, `listen_history` | пользовательские действия |

## Kafka

Kafka используется для входящих событий. После восстановления БД consumer продолжает чтение согласно offset consumer group. DLT сохраняет сообщения, требующие ручного разбора.

> Требует уточнения: production RPO/RTO и политика retention для Kafka topics.

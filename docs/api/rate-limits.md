# Ограничения частоты запросов

Ограничение частоты запросов на уровне приложения в текущем коде отсутствует. Ограничения задаются внешним уровнем: API gateway, reverse proxy или ingress.

## Рекомендуемые зоны контроля

| Область | Причина |
|---|---|
| `GET /search` | полнотекстовые запросы к БД |
| `GET /search/suggest` | высокая частота во время ввода |
| `POST /podcasts/{podcastId}/vote` | защита от частых переключений |
| `POST /authors/{authorId}/subscribe` | защита от частых изменений счётчика |
| `POST /podcasts/{podcastId}/progress` | частые события плеера |

> Требует уточнения: production-политика ограничения частоты запросов на уровне nginx/API gateway.
